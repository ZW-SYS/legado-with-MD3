# 阅读Max

基于 [legado-with-MD3](https://github.com/HapeLee/legado-with-MD3) 二次开发的安卓阅读器。

在保留原版全部功能的基础上，新增了对 **.nex 格式**的完整支持。

---

## .nex 格式

`.nex` 是由 **ZW-SYS** 设计并实现的电子书格式，首次定义于 2026-10-03。

本质上是一个 ZIP 压缩包：

    mybook.nex
    ├── manifest.json      书名、作者、格式版本、作者署名
    ├── book.json          章节列表
    ├── content/
    │   ├── ch1.html       每章正文（HTML）
    │   └── ch2.html
    ├── assets/
    │   ├── img/           图片
    │   └── video/         视频
    └── style/main.css     样式

### 格式来源

- **设计者**：ZW-SYS
- **首次实现**：本仓库 commit `0d308f0`（2026-10-03）
- **实现代码**：`NexConverter.kt`、`NexFile.kt`
- **参考实现**：https://github.com/ZW-SYS/legado-with-MD3

本格式由 ZW-SYS 定义。任何人可以自由实现与使用，但请保留出处。

## 新增功能

- **导入 .nex 书籍** —— 书架「添加本地」和「智能扫描」都支持
- **转 .nex** —— 书架三点菜单 → 转 .nex，支持 EPUB / DOCX / TXT
  - EPUB：从 NCX / nav.xhtml 读取真实目录标题，抽取图片与视频
  - DOCX：优先按标题样式切章；无标题时按「第X章」等文本自动切章
  - TXT：自动探测章节
- **视频播放** —— 带视频的章节，阅读页右上角显示 ▶ 按钮，点击用系统播放器播放
- **图片显示** —— `.nex` 内图片正常渲染
- **局域网分享** —— 同一 Wi-Fi 下其他设备可通过浏览器下载你书库里的书
- **开屏鼓励语** —— 每次启动显示一句随机鼓励语

---

## 局域网分享怎么用

1. 手机打开阅读Max，进 **设置 → 高级**，开启「启动应用时打开 Web 服务」
2. 记住 Web 端口（默认 1122，可改）
3. 同一 Wi-Fi 下，其他设备浏览器打开：

       http://你的手机局域网IP:1122/share

   比如 `http://192.168.1.46:1122/share`
4. 就能看到书库里的书，点「下载」

## 安装

1. 在 [Releases](../../releases) 页面下载最新 APK
2. 如遇签名冲突，先卸载旧版再安装

## 已知限制

- 不支持音频（`.nex` 内也不生成音频）
- PDF 暂不支持转换
- 视频为外部播放器播放，不内嵌在正文流中
